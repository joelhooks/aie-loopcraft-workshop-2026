Use VISION.md from Lesson 01. Create issues.jsonl or data/issue-events.jsonl with ready, approval-required, and input-required examples. Add the smallest local check command that validates every row, fails loudly on bad input, prints the file read, event count, classifications, stop reasons, next allowed action, and refused action. Build it on a strict Matt Pocock-style TypeScript config with tsgo, oxlint, oxfmt, and Ultracite for fast strict checks, and use an Effect Schema to parse each row so bad input fails with a typed error — read .agent_sources/effect for idiomatic Schema usage first. Add tests, run the commands from the repo root, and save one receipt from real output. After the checks exist, install Lefthook: pre-commit must call the package scripts for typecheck, lint, and format checks; pre-push must call the full check including tests. Run pnpm exec lefthook install and verify both hooks with pnpm exec lefthook run pre-commit --all-files and pnpm exec lefthook run pre-push --all-files. Save actual hook output; skipped jobs are not a pass. Do not commit or push just to verify hooks. Keep it local; do not add auth, external issue APIs, GitHub writes, schedulers, or background workers yet.
